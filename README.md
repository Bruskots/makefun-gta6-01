Solmar Bay — an original top-down open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC. Explore a coastal city on foot and by car, steal cars, dodge the police across a 0–5 star wanted level, and run 5 story missions as Rico Vega. Vanilla JS + Canvas 2D, no build step, no network.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080 (or serve game/ with any static HTTP server and open game/index.html).
